# Añadir español (fase posterior)

La web se publica solo en inglés (`lang="en-US"`). Para añadir español:

1. En `astro.config.mjs`, pon `i18n.locales: ['en', 'es']`.
2. Crea `src/pages/es/...` con las mismas rutas traducidas: `/es/limpieza-regular/`, etc.
3. Añade `hreflang` recíproco (`en-US` / `es-US` / `x-default`) en `src/layouts/Base.astro`. Hoy el QA marca error si aparece hreflang, porque no existe ninguna traducción.
4. Traduce `src/data/*.ts` a archivos `*.es.ts`. No uses traducción automática sin revisión.
5. Las reseñas en español ya están marcadas con `lang="es"`.
